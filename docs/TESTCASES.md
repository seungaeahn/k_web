# 실실 테스트 케이스

## 실행 방법

```bash
node tests/run.js        # 전체
node tests/run.js PRJ    # 번호 앞부분으로 골라서 (예: PRJ, SMP, JAR)
```

- 설치할 것 없음. 로컬 서버를 띄우고, 이미 깔린 Chrome(없으면 Edge)을 화면 없이 실행해서 `tests/index.html?demo=test`를 돌려요. Chrome 위치가 다르면 `CHROME_PATH` 환경변수로 알려주세요.
- 테스트는 실제 앱 화면을 띄워 버튼을 누르고 입력하며 확인해요. 저장소는 **메모리 테스트 모드**(`?demo=test`)라서 실제 기록(localStorage, 도안 파일)은 건드리지 않아요.
- 브라우저에서 `http://localhost:8080/tests/index.html?demo=test`를 직접 열어도 돌아가요. 결과는 개발자 도구 콘솔에 나와요.
